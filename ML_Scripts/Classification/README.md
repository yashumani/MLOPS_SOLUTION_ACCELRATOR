

# Classification Model Pipeline

## Overview

This Python script implements a complete end-to-end classification model pipeline using advanced tools like **PyCaret**, **FLAML**, and **Sweetviz**. The script covers:
- **Exploratory Data Analysis (EDA)**
- **Data Cleaning and Preprocessing**
- **Model Training and Hyperparameter Tuning**
- **Model Comparison**
- **Performance Evaluation and Visualization**

## Key Features

1. **Exploratory Data Analysis (EDA)**:  
   - Utilizes **Sweetviz** to generate detailed, interactive EDA reports.  
   - Automatically highlights dataset statistics, distributions, and correlations.

2. **Data Cleaning**:  
   - Handles missing values by filling with medians for numeric columns.  
   - Removes duplicates and extreme outliers based on percentile thresholds.  

3. **Preprocessing**:  
   - Splits data into numeric and categorical features.  
   - Encodes categorical variables using **OneHotEncoder**.  
   - Standardizes features for consistent model input.

4. **Model Training**:  
   - **PyCaret**: Provides a low-code interface to compare multiple classification models.  
   - **FLAML**: Uses lightweight AutoML for efficient model training with custom hyperparameter tuning.

5. **Hyperparameter Tuning**:  
   - Incorporates **Optuna** to tune PyCaret models with user-defined parameter grids.  

6. **Performance Evaluation**:  
   - Generates accuracy, confusion matrix, and classification reports for models.  
   - Visualizes model performance using heatmaps and metrics.

7. **Logging**:  
   - Logs each step of the pipeline, enabling traceability and debugging.

## How to Run

1. **Prepare Dataset**:  
   Ensure your dataset is saved as a CSV file and update the `DATA_PATH` variable with the file path.

2. **Adjust Constants**:  
   - `TARGET_COLUMN`: Update with the name of the target column in your dataset.  
   - `REPORTS_PATH`: Directory to save generated reports and visualizations.  

3. **Execute Script**:  
   Run the script using:
   ```bash
   python Classification_1_3.py
   ```

4. **Results**:  
   - View EDA reports in the specified `REPORTS_PATH`.  
   - Review logs for process insights in `logs.log`.  
   - Model performance metrics, visualizations, and comparisons will be printed in the console and saved in the reports directory.

## Code Workflow

1. **EDA**:
   - Generates detailed insights using **Sweetviz**.
   - Saves EDA reports in HTML format.

2. **Data Cleaning**:
   - Handles missing values and outliers.  
   - Ensures clean and standardized input for model training.

3. **Data Preprocessing**:
   - Splits the data into training and testing subsets.  
   - Applies one-hot encoding for categorical features.

4. **Model Training**:
   - Compares models using **PyCaret** to identify the best baseline.  
   - Uses **FLAML** for lightweight AutoML-based classification.

5. **Hyperparameter Tuning**:
   - Optimizes the selected PyCaret model using **Optuna**.

6. **Performance Visualization**:
   - Generates confusion matrices and classification reports for evaluation.  
   - Saves visualizations for easy comparison.

## Outputs

- **EDA Reports**: Interactive HTML reports generated by Sweetviz.  
- **Logs**: Process details stored in `logs.log`.  
- **Model Visualizations**: Confusion matrix heatmaps and metrics.  
- **Best Model**: Identifies the top-performing model (PyCaret or FLAML) based on accuracy.
