# Production hardening: P1 + P5 + P6 (backend scope)

Backend-owned hardening for the V3 pipeline. **Does not touch the FastAPI surface
under `api/`** (Codex's scope) — except the shared `api/core/azure_ml.py` and
`api/core/config.py` credential/chain wiring, which must be coordinated before merge.

## Scope (locked product defaults)

1. Channels: **Teams webhook + Azure Communication Services email**
2. Schedule: **hourly week 1, daily after**
3. Retraining: **alert-only for the first 30 days**
4. Pipeline: **dedicated drift-only pipeline**
5. Phase 4 ships **without concept drift**

## Required env vars

**Mandatory (Azure context):** `AZURE_SUBSCRIPTION_ID`, `AZURE_RESOURCE_GROUP`,
`AZURE_WORKSPACE_NAME`, `AZURE_COMPUTE`.

**Optional (alerts — channels no-op when unset):** `TEAMS_WEBHOOK_URL`,
`ACS_CONNECTION_STRING`, `ACS_SENDER_ADDRESS`, `DRIFT_ALERT_RECIPIENTS`.

> The committed `.env` exposes `COMPUTE_TARGET`, not `AZURE_COMPUTE`. After
> `source .env`, run `export AZURE_COMPUTE="${COMPUTE_TARGET}"` before submit.
