# Blueprints Directory

This folder contains project blueprint documents for the MLOps Solution Accelerator V3.

Blueprints track the **Data Science Lifecycle Stages**, libraries, problem types, methods, datasets, domains, and key performance metrics across all pipeline phases.

## Files

| File | Description |
|------|-------------|
| `V3_Production_Blueprint.md` | Full V3 Production Blueprint in Markdown format |
| `V3_Production_Blueprint.csv` | Same blueprint data in CSV tabular format |
| `V3_Variant_Inventory.md` | Comprehensive variant inventory — Section A (457 existing across classification/regression/clustering + shared) & Section B (81-145 planned) |
| `V3_Variant_Configurations.csv` | All 457+ variant YAML configurations extracted into 38-column CSV |
| `V3_Imputation_Strategy_Expansion.md` | Imputation method expansion blueprint — 6 current → 33 proposed methods, industry-specific analysis, decision matrix, implementation phases |
